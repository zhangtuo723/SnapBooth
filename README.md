# SnapBooth

SnapBooth 是面向活动现场的现拍现打 App。**iPad 是主平台**：iPad 新增 USB/PTP 直连 EOS R50 V 真快门链路（已在 iPad + R50 V 真机验证拍摄及照片回传），并保留 Canon CCAPI/Wi-Fi 链路，自动下载、保存、排版，再通过系统分享把成片交给米家 App，由用户在米家确认打印。Mac 版仅作为 USB 协议验证、开发调试和应急备用，不作为产品主链路。

## iPad 主链路状态

- EOS R50 V：已接入 Canon CCAPI。iPad 可通过 HTTP/HTTPS Wi-Fi 实时取景、触发真快门与 AD-E1 热靴闪光，并从存储卡自动下载新增 JPEG；支持佳能 Digest 用户认证，自签名证书仅对所配置的相机主机放行，密码保存在 iPad 钥匙串。UVC 只作为无闪光备用取景。
- 米家桌面照片打印机 2：iPad 默认“米家打印”模式。拍摄后点击“去米家打印”弹出系统分享面板，选择米家（未显示时查看“更多”）。边框和模板在拍摄前设置，实时取景、拍后预览与分享图片使用同一套合成效果。由米家选择匹配的相纸并确认打印，需保留完整图片，避免二次边框或裁切。用户已验证 SnapBooth 分享可以进入米家；分享完成不代表打印完成，取消分享保留当前照片。不提供私有 BLE 直连打印。
- AirPrint：仅作为其他兼容打印机的备选。当前这台二代打印机未在局域网公告 IPP/IPPS 服务。
- USB 直连排查：iPad 的“打印 → 相纸与设备检测 → USB 设备检测”提供系统相机设备与 ExternalAccessory 的只读检测，可复制、分享报告。它不会创建打印任务；当前尚未实现 A16 iPad 的米家 USB 直接打印。
- iPad 验收标准：所有主功能必须在 iPad 真机完成。Mac Catalyst 构建通过只用于防止备用版回归，不代表 iPad 主链路已完成。

### A16 iPad USB 直连验证

现有 Mac 后端通过 `libusb` 打开 `302c:3008`，占用接口 `2`，在 `0x06/0x86` 端点发送厂商命令和 JPEG 数据。任务协议已验证，但 Mac 的 `libusb` / 辅助进程访问层不能直接迁入 iPad。苹果目前说明 [iPadOS DriverKit 要求 M 系列芯片](https://developer.apple.com/documentation/driverkit/creating-drivers-for-ipados)；A16 的系统相机或 MFi 配件接口是否适用，还取决于打印机提供的功能。

1. 给打印机接电，用数据线连接解锁的 iPad。首次检测建议先只连接打印机，便于辨认结果。
2. 在拍摄工作台进入“打印 → 相纸与设备检测 → USB 设备检测”，等待约 15 秒，必要时刷新或重插。页面会记录系统访问权限；请求权限须由用户点按钮。
3. 复制或分享报告，也可从“文件 → 我的 iPad → SnapBooth”取出 `PrinterUSBDiagnostics.txt`，之后连接 Mac 也可以读取。

检测仅枚举，不打开相机会话、不读取照片、不发送 PTP/打印命令。ImageCaptureCore 只显示系统识别的相机设备；ExternalAccessory 也可能包含蓝牙设备，无法据此确认 USB 连接。发现设备不代表支持打印，未发现也不能证明没有物理连接或排除所有通信方案。ExternalAccessory 协议列表为空也可能是尚未认证，见 [Apple protocolStrings 文档](https://developer.apple.com/documentation/externalaccessory/eaaccessory/protocolstrings)。

2026-10-31 已采集这台打印机的全部配置、接口及端点，见 [USB 实机记录](docs/hardware/mijia-usb-2026-10-31.md)。它只有一个配置，包含标准双向打印接口 `07/01/02`、Debug 厂商接口和现有 Mac 后端使用的 `WinUSB_Eg` 厂商接口；未发现 PTP、USB 网络或 IPP-over-USB 接口。标准设备 ID 报告 `CMD:DC_RASTER`。结合 A16 真机的 IC/EA 空列表，目前仍没有可用的 A16 公开 USB 直打路径；不能仅靠修改 App 或重复刷新打通。Mac 本次仅用于读取接口，无需长期驻留。

### 自研 App 内直接打印研究

目标是独立完成打印，不分享或跳转米家。2026-10-31 已由独立 CoreBluetooth 工具直接连接这台打印机，取得 MiBeacon PID `29841`、`FE95` 及 STDIO 服务完整拓扑；这证实 BLE 连接不必由米家建立，尚未验证认证和照片传输。见 [蓝牙实机记录及协议研究](docs/hardware/mijia-ble-2026-10-31.md)。小米公开文档显示同类通道需要授权登录和会话加密；当前没有独立蓝牙打印功能，旧实验移除记录也不能当作蓝牙不可行的证据。

## 工作台 UI

流程为「首页 → 模板选择 → 拍照 → 确认成片 → 去米家打印」。首页点击“开始拍摄”先进入独立选择页，选好后点击“开始拍摄”才启动相机。拍摄页的“更换拍摄模板”可重新选择，取消选择会保留原样式。

拍摄页将动态相机画面、完整分辨率模板与原生文字分层显示，避免低清实时帧把插画和文案一起缩小；静态装饰只在样式或画布变化时更新。保存和打印仍以完整分辨率合成。

模板编辑页使用 1800×1200 完整分辨率背景预览，文字以原生图层清晰显示。切换到「自定义文案」可添加多段中英文，通过菜单选择字体和颜色、调整字号与文本框宽度；直接拖动画面中的文字可改变位置。内置婚礼标题同样可编辑或删除，确认后的文案会同步到实时取景、保存、分享及打印。

模板库提供三款图形绘制风格（时刻杂志、复古暗房、奶油拍立得）、六款图片生成的纸感花材边框（誓言留白、柔雾玫瑰、鼠尾草花园、朱砂金线、白玫瑰之约、晴蓝金线），以及可选边框颜色的纯净款。默认标题均可编辑、移动和删除。

图片素材保留生成时的 alpha 并打包在 Assets.xcassets 中，运行时将全部装饰限制在精确的 3:2 照片窗口之外。装饰模板固定为 6 英寸横向单张；实时预览、保存和输出使用同一渲染路径。纯净款仍支持原有尺寸与排版设置。

拍摄页采用暖白和墨绿配色，使用「照片 / 相机 / 打印」三个设置分栏：照片分栏选择滤镜，并在折叠的“尺寸与构图”中调整旋转、完整显示方式与排版；相机分栏选择与恢复相机；打印分栏选择输出方式，并在“相纸与设备检测”中查看相纸设置和 USB 检测入口。主操作区拍摄前显示“拍照”，拍摄后原位切换为“重拍”和“去米家打印”（其他输出模式显示对应操作）。宽窗口左右排列，窄窗口上下排列；取景区右上角可收起或展开整组设置，已选配置保留。首页活动背景和文案仍可单独编辑。

真实拍摄仍会自动保存拍摄时的成片。拍后继续编辑会标明当前调整未保存，点击“保存当前成片”可另存修改后的版本；打印与分享使用当前预览的成片。

在 Mac 上预览 UI 可直接使用内置摄像头，无需连接佳能相机或打印机。查看界面不会发送打印任务；实际拍摄仍会按原有流程自动保存照片。iPad 分享已合成边框与模板的成片到米家；Mac 点击打印后仅弹出确认，不再进入独立模板编辑页。

## Mac 使用

1. 用 USB/Type-C 将 Canon 相机和米家桌面照片打印机 2 同时连接到 Mac。
2. 打开 `SnapBooth.xcodeproj`，选择 **My Mac (Mac Catalyst)**。
3. 首次构建前安装编译依赖：`brew install libusb gphoto2`。米家辅助程序静态链接 libusb；佳能辅助程序运行时仍依赖 Homebrew 的 libgphoto2。
4. 运行并允许相机权限。
5. 确认“相机”分栏显示 Canon 相机，“打印”分栏显示“米家桌面照片打印机 2 已连接”。
6. 装好米家 6 寸相纸和对应色带。
7. 按“拍照”；倒计时完成后会自动生成最终 JPEG 并保存到 `图片/SnapBooth`。确认预览后，按“打印照片”并确认，才会发送打印任务。

“存到文件”只在 App 文稿中保存 JPEG，不会出纸；真实打印必须手动按“打印照片”并确认。

## iPad 通过 Type-C 连接佳能 R50 V（已验证拍摄及照片回传）

1. 相机切到照片模式，插入存储卡，图像格式选择 JPEG 或 RAW+JPEG。
2. 在相机“通信功能 → 选择 USB 连接应用程序”中选择“照片导入/遥控”；关闭 Wi-Fi。不要选择 UVC 串流或“适用于 iPhone 的佳能应用”。
3. 使用支持数据传输的双端 Type-C 线连接 iPad 与相机，关闭其他占用相机的 App。
4. 在 SnapBooth 点击“开始拍摄”，选择“佳能 USB · Type-C 遥控”，允许系统弹出的相机控制及内容读取权限。
5. 等待连接状态与取景画面，再手动点拍摄。热靴闪光由相机自身设置决定，App 的设备相机闪光开关不控制外置闪光灯。
6. 拍摄后读取本次新增 JPEG 并沿用现有保存和米家分享流程。USB 超时不会自动重拍；先检查相机和存储卡，再通过相机菜单重新连接。“取回”仅尝试本次已识别的待下载对象，不会选择历史照片冒充本次成片。

实现使用 Apple ImageCaptureCore 的公开 PTP 接口；佳能 EOS 操作码和数据布局参考 [libgphoto2 协议定义](https://github.com/gphoto/libgphoto2/blob/master/camlibs/ptp2/ptp.h)，Swift 传输与流程代码独立实现，没有将 libgphoto2 链接进 iPad App。

## iPad 连接佳能 R50 V

1. 在相机进入 `高级连接 → Camera Control API`，连接与 iPad 相同的 Wi-Fi，并保持相机停留在“通信中”。
2. 在 SnapBooth 的相机选择菜单中点“设置佳能 Wi-Fi 地址”。
3. 粘贴相机显示的完整 URL（例如 `https://192.168.1.11/ccapi`），按相机设置填写用户名和密码。
4. 等待状态显示已连接的相机型号并出现取景画面，再点“拍照”。成片会保留在相机存储卡，同时自动保存到 iPad 照片图库。

不要从 macOS 系统打印窗口选择当前的 `Mijia Instant_Photo_Printer_2` 队列：本机把它错误识别为 DYMO 标签打印机。SnapBooth 的“USB 打印”模式会绕过该队列。

## 功能

- 自动发现 AVFoundation 可识别的内置或 USB 相机；
- 相机切换、实时预览和 0/3/5/10 秒倒计时；
- 统一 3:2 照片窗口，默认完整画面，可手动选择铺满裁切；
- 暖阳、清透、胶片、黑白、复古滤镜及强度调节；
- 满版、四宫格、双联照片条；
- 1 寸、2 寸证件照精确拼版和裁切线；
- 米家桌面 6 寸纸默认画布 `100 × 148 mm`；
- 保存当前成片、存到文件、米家分享打印、AirPrint 和 Mac 米家 USB 直连。

## 当前限制

- Canon CCAPI 需要 R50 V 和 iPad 同处一个可互访的 Wi-Fi；相机端账号或密码修改后，需要在 App 中同步更新。
- Mac USB 后端目前只为米家桌面照片打印机 2 的 6 寸照片路径配置。
- iPad 不提供米家 BLE 直连打印；旧探测与认证实验代码已移除。
- 1/2 寸模板只保证物理尺寸和拼版，不代表符合特定证件的拍摄规范。
